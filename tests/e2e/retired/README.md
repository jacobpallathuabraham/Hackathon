# Retired suites

These suites tested screens that no longer exist. They are kept for history and are not run.

- `handwriting-v22.e2e.js` tested the v22 Handwriting Studio (`.hxs__*` markup, `ERLY.handStudio`). The studio was rebuilt in v24. Its replacement is `tests/e2e/handwriting-studio-v24.e2e.js`. The ink-transition checks for the student portal → Handwriting route are still in `tests/e2e/ink-studio.e2e.js`.
